## Com obrir els projectes

1. Clona el repositori:
   ```bash
   git clone https://github.com/andro-client/stucom-java-RA1RA3.git
   cd stucom-java-RA1RA3
   git checkout tasks
   ```
2. Obre NetBeans i ves a **File → Open Project**.
3. Selecciona la carpeta del projecte que vulguis executar i prem **Run** (F6).
